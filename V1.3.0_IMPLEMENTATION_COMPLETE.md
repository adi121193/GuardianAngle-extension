## Known Limitations

1. **Progress Bar:** Currently simulated (0-100% in 3 seconds)
   - Real implementation would track actual model download
   - ONNX Runtime Web downloads models transparently
   - Future: Hook into `fetch` progress events

2. **NER Status Polling:** Status chip queries background on load
   - Real-time updates via message passing
   - Could add periodic polling if needed

3. **Model Size:** Download prompt shows "~10-15 MB"
   - Actual size depends on model selected
   - Current placeholder until final model chosen

## Integration Points Verified

### ✅ Popup ↔ Background Communication
- `INIT_NER` message sent on download
- `NER_STATUS` message returns initialization state
- `NER_STATUS_CHANGED` broadcast from background

- Settings loaded on popup open
- State saved on toggle/download
- `nerModelDownloaded` persists across sessions
- `nerNeverAsk` prevents future prompts

### ✅ Background ↔ Content Scripts
- `NER_READY` broadcast to all tabs
- Content scripts update detection mode
- Hybrid detector uses NER when available

### ✅ Detection Panel ↔ Hybrid Detector
- Detection results include `source` field
- Panel renders badges based on source
- Summary shows regex vs NER breakdown
- Performance notice when NER unavailable
